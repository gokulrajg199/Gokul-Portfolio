# G. Gokulraj — Advanced AI Portfolio

A premium, responsive academic and innovation portfolio with an AI-inspired visual system.

## Features
- Animated neural-network canvas background
- Glassmorphism and aurora effects
- Interactive 3D tilt cards and magnetic buttons
- Animated research metrics and scroll progress
- Responsive mobile navigation
- Research, funded projects, mentorship, credentials and entrepreneurship sections
- Certificate gallery linked to source credentials
- Endless Xplorers brand integration

## Run locally
Open `index.html` in a modern browser. For best results, serve the folder locally:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy
Upload the folder to GitHub Pages, Netlify or Vercel. No build step is required.
